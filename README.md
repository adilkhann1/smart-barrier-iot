# Smart Barrier IoT System

## 📌 Project Description
An IoT-based automated access control system developed using ESP32 and ESP32-CAM.  
The system recognizes vehicle license plates and automatically controls a barrier based on identification results.

## 🚀 Features
- Image capture using ESP32-CAM
- Wireless data transmission via Wi-Fi
- License plate recognition
- Automatic barrier control upon successful identification
- Integration of hardware and software components into a single IoT system

## 🛠 Technologies
- ESP32 / ESP32-CAM
- Arduino IDE
- C / C++
- Wi-Fi, HTTP
- Sensors and actuators

## 🎯 Result
A fully functional prototype of an automated access control system.  
The project provided hands-on experience in designing, programming, and integrating an IoT device from concept to working solution.
